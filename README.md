# Readme

## Leaflet & React Leaflet

[Leaflet](https://leafletjs.com/) ist eine Bibliothekt für Webkarten. React Leaflet ist ein "Wrapper", welcher die Verwendung von Leaflet in React Projekten ermöglicht.

### Installation

Siehe: https://react-leaflet.js.org/docs/start-installation/ - nur der Abschnitt "Using a package registry" ist für dich relevant.

- Installiere zunächst leaflet (mit npm i). React und React-Dom sollten bereits durch Vite vorinstalliert sein und müssen dann nicht nochmals installiert werden.
- Installiere dann react-leaflet (mit npm i)
- Beachte das Beispiel, wie React-Leaflet-Komponenten importiert werden.

### Hinweise

Du benötigst ausserdem Leaflets CSS Stile. In der App.jsx-Datei füge diese Zeile hinzu: `import "leaflet/dist/leaflet.css";`
